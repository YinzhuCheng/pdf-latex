文字夹逼法算法说明：
1. OCR 提取页面所有文字及精确坐标
2. 识别图标题（"图 X.X" / "Figure X"）
3. 找到图标题上方最近的段落文字（有显著间距）
4. 图片上边界 = 上方文字底部 + padding
5. 图片下边界 = 图标题顶部 - padding
6. 左右边界通过像素密度扫描确定
